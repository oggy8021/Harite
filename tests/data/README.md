テスト用画像ディレクトリ

このディレクトリには、`tests/test_core.py` が参照する代表画像を配置します。
現状、母体プログラムから有用な画像が見つかっていないため、サンプル画像を手動で追加してください。

推奨ファイル名（テストと一致させるため）:
- `img_wide.jpg` — ワイド画像（例: 1920x1080）
- `left.jpg` — 左モニタ用サンプル
- `right.jpg` — 右モニタ用サンプル

画像が追加されたら、テストを実行してください:

```bash
python -m pytest tests/test_core.py -q
```
