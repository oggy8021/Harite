# mini向け 作業見出しテンプレ

最終更新: 2026-04-12

## 使い方

- このテンプレは docs-only タスクを mini モデルで実装するときに使う。
- `<>` は案件内容で置き換える。

## テンプレ本体

```md
# <タイトル>

最終更新: YYYY-MM-DD

## 目的

- <何を防ぐ/改善するか>

## 対象

- ファイル: `<path/to/file.md>`
- スコープ外: <必要なら記載>

## 判定（最初に判断すること）

- 条件A: <分岐条件>
- 条件B: <分岐条件>

## 手順（実行順）

1. <手順1>
2. <手順2>
3. <手順3>

## 確認コマンド

```bash
<command 1>
<command 2>
<command 3>
```

## 期待結果

- <成功時の状態>
- <失敗時の典型症状>

## 失敗時の回復

1. <回復手順1>
2. <回復手順2>

## 注意点

- <禁止事項 or 誤りやすい点>

## 完了条件

- [ ] <検証項目1>
- [ ] <検証項目2>
```

## 記述ガイド

- 文は短く（1項目1文）書く。
- 見出し順は固定する。
- コマンドはコピペ可能な最小セットにする。
- 手順内に説明を詰め込みすぎず、注意点へ分離する。
