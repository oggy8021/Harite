# Harite リリース準備チェックリスト

最終更新: 2026-03-20

## 使い方

- このチェックリストは「リリース候補（RC）確定」から「タグ作成」までの抜け漏れ防止を目的とする。
- 各項目は、実施後に PR コメントまたはリリースノート草案へ証跡（コマンド結果・スクリーンショット・ログ要約）を残す。
- ブロッカーが 1 つでもある場合は、リリースを延期し、原因と再開条件を記録する。

## 1. コード・ブランチ状態

- [ ] `main` が `origin/main` と同期している。
- [ ] オープン PR のうち、当該リリースに含める/含めないを明示できている。
- [ ] ブランチ保護ルール（必須チェック・レビュー要件）が有効である。
- [ ] 直近でマージした高リスク変更（壁紙適用ロジックなど）を一覧化できている。

## 2. テストと品質ゲート

- [ ] ローカルで `pytest` が成功している。
- [ ] GitHub Actions の必須 CI が成功している。
- [ ] 失敗中または不安定（flake）なテストがない。
- [ ] 新規テスト（今回の変更に対応）が追加済み、または不要理由を説明できる。

## 3. 実行確認（CLI）

- [ ] `harite optimize --help` の表示を確認した。
- [ ] `harite apply --help` の表示を確認した。
- [ ] `apply` は dry-run が既定であることを再確認した。
- [ ] `--do-it` 実行時の注意事項を README と整合させた。

## 4. Linux/XFCE 向け最終確認

- [ ] `xfconf-query` が利用可能な環境で dry-run を再実行した。
- [ ] XFCE 実機で `--do-it` を使ったとき、壁紙が実際に切り替わることを確認した。
- [ ] 相対パスではなく絶対パスで適用されることをログまたは設定値で確認した。
- [ ] 問題発生時の切り戻し手順（既知の良い画像へ再設定）を確認した。

## 5. ドキュメント・運用

- [ ] README の操作例が現行 CLI と一致している。
- [ ] `docs/TODOs_jp.md` の進捗が最新化されている。
- [ ] 変更に対応するドキュメント（PR フロー、運用ルール等）が更新済み。
- [ ] 次タスク（CI で sdist/wheel build）への引き継ぎ事項を記録した。

## 6. リリース実施（最終）

- [ ] バージョン番号を確定した。
- [ ] リリースノート草案（変更概要、注意点、既知の制約）を作成した。
- [ ] リリースタグ作成手順を実行し、参照コミットを確認した。
- [ ] リリース後の監視ポイント（不具合受付窓口、初期フィードバック確認日）を決めた。

## 付録: 最低限の実行コマンド例

```bash
pytest
python -m harite.cli optimize --help
python -m harite.cli apply --help
python scripts/xfce_smoke_runner.py --input /abs/path/to/wallpapers --iterations 5
```
