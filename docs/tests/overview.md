
この文書は `tests` ディレクトリに含まれる主要なテスト群の「仕様的説明」を外部の読者やレビュア向けに平易な日本語でまとめたものです。

目的:
- テストが何を検証しているかを明確に示し、開発者やレビュアが期待される振る舞いを一目で理解できるようにする。

対象読者:
- コードベースを初めて読む開発者、ドキュメントレビュア、CI 管理者。

ドキュメント構成:
- 概要（このファイル）: 高水準の目的・範囲・実行方法。
- テスト仕様: 各テスト関数の目的・セットアップ・主要アサーション・拡張案（下に列挙）。
- 付録: テスト本体のコードは付録ファイルに移し、実際のコードはそちらを参照してください: `docs/tests/appendix_tests_code.md`。

実行方法（ローカル）:
1. 仮想環境を有効化（Windows PowerShell の例）:
```
& .venv\Scripts\Activate.ps1
```
2. 開発依存をインストール:
```
python -m pip install -r requirements-dev.txt
```
3. テスト実行:
```
python -m pytest -q
```

テスト仕様（要約）:
- `test_optimize_wallpapers_creates_output_and_placements`
    - 目的: `optimize_wallpapers` が出力ファイル群を生成し、配置情報（placements）を返すことを検証。
    - セットアップ: 2つの入力画像を作成し、ターゲット解像度 `(800,600)` と出力ディレクトリを与える。
    - 主要アサーション: 返却された `saved` がファイルを含み、`placements` がリストで元画像名を参照すること。
    - 拡張案: 出力ファイル名パターン、画質・メタデータ、重複入力の扱い、エラー時の挙動を追加で検証。
- `test_compute_placement_centers_and_scales`
    - 目的: `compute_placement` がターゲット領域に収まる幅・高さと非負の座標を計算することを検証。
    - セットアップ: 単一画像を生成して `(800,600)` を渡す。
    - 主要アサーション: `pr.width/height` がターゲット以下、`pr.x/pr.y` が0以上。
    - 拡張案: アスペクト比保持、切り抜き vs フィット戦略、最小スケール制約を検証。
- `test_split_composite_for_displays_creates_per_display_files`
    - 目的: `split_composite_for_displays` が複合画像から各 `Display` 用の切り出しファイルを作ることを検証。
    - セットアップ: 横長の合成画像と 2 つの `Display`（左/右）を用意。
    - 主要アサーション: 戻り値が辞書でキーにディスプレイ名があり、生成ファイルが存在し期待サイズを持つこと。
    - 拡張案: オーバーラップ表示、スケーリング／パディング方針、異なる DPI/回転の扱いを追加検証。
