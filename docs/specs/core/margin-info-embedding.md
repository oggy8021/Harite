# 余白への情報埋め込み仕様（MVP）

最終更新: 2026-03-21

## 目的

- `harite optimize` で生成される画像の余白領域を活用し、必要最小限のテキスト情報を埋め込めるようにする。
- まずは小さく始めるため、**画像本体への重ね描画（オーバーレイ）は対象外**とする。
- 情報量が多くなった際の扱いを、初期段階から明確にする。

## スコープ

### 当面（MVP）

- 何も埋め込まない（デフォルト）
- optimize で指定したパラメータの記載
- フリーワード

### 将来候補（本仕様では未実装）

- 電子透かし
- 天気情報
- ホスト名 / OS バージョン / ユーザ名
- CPU 使用率などのモニタ情報

## 基本方針

- デフォルトは無効（現行見た目を変えない）。
- 表示先は「余白のみ」。余白が不足する場合は安全に省略する。
- 可読性優先。見た目の派手さより、壊れにくさと意図の明確さを優先。
- 一度に詰め込みすぎない。MVP は単一テキストブロックのみ。

## CLI 仕様案

`harite optimize` に以下を追加する。

- `--embed-info [none|params|free|combo]`
  - 既定値: `none`
  - `params`: optimize パラメータ要約
  - `free`: `--embed-text` の内容
  - `combo`: 上記を結合（順序は固定）
- `--embed-text TEXT`
  - `--embed-info=free` または `combo` 時に使用
- `--embed-position [top|bottom|left|right|auto]`
  - 既定値: `auto`
  - `auto` は余白量が最大の辺を選択
- `--embed-max-lines INT`
  - 既定値: `3`
  - 上限超過時は末尾を `...` に省略

補足:

- MVP ではフォントや色の細かな指定は追加しない。
- まずは既定スタイル固定で実装し、必要性が出た時点で拡張する。

## 表示ルール（MVP）

- 埋め込み先は余白領域のみ。
- 余白ゼロ、または最小描画高さを満たせない場合は描画をスキップし、ログで通知する。
- 複数行テキストは改行で構成し、`--embed-max-lines` を超える分を切り詰める。
- `params` の出力は「再現性に重要な項目」を優先し、冗長項目は省略する。

推奨の `params` 出力例:

- resolution
- margins
- align / valign
- padding
- two-screen 関連（有効時のみ）
- input 件数（パス全文ではなく件数）

## 情報量過多への対応

MVP 時点では次の優先順位で整理する。

1. 行数制限で切り詰める
2. `params` の詳細を要約化する
3. どうしても収まらない場合は描画をスキップし、ログ出力する

「縮小して無理やり全表示」は可読性を壊すため採用しない。

## セキュリティ / プライバシー方針

- `params` は値をそのまま出すが、機微情報になり得る絶対パスやユーザ名は MVP で出力しない。
- `free` はユーザ明示入力のみ描画する。
- 将来のホスト情報系は `opt-in` かつ個別フラグでのみ有効にする。

## 実装方針（段階）

1. テキスト生成層を分離
   - `build_embed_text(mode, embed_text, runtime_context)` のような純関数で文字列を作る
2. 余白判定と描画層
   - 既存キャンバス生成後に「余白領域判定 -> 描画可否判定 -> 描画」を行う
3. CLI 統合
   - 新オプションを `optimize` に追加し、core へ渡す
4. テスト追加
   - テキスト生成ユニットテスト
   - 余白不足時のスキップ挙動テスト
   - `combo` の行数制限テスト

## 受け入れ基準（MVP）

- 既定動作（`--embed-info=none`）では出力画像が現行と一致する。
- `params` / `free` / `combo` が指定通りに文字列化される。
- 余白不足時は例外で落ちず、埋め込みをスキップできる。
- 行数制限が機能し、長文でレイアウト崩壊しない。

## 非目標（MVP）

- 画像本体への文字重ね描画
- 透かしアルゴリズム
- 外部データ取得（天気、監視メトリクス）
- OS/ホスト情報の自動収集

## 変更時の更新ルール

以下を変更した場合は本書を更新する。

- `--embed-info` のモード定義
- 余白不足時の扱い
- 行数制限と省略ポリシー
- 機微情報の出力ポリシー
