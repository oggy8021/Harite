### 意図的に残す項目（follow-up）

| 項目 | 理由 |
|------|------|
| **P3-3 表示構成変化の即時 re-sync** | planning §4 gate。`dual_display_available` は都度検出するが widget fade は owner-sync タイミング |
| **GTK slideshow C-02 widget + P-03 disable** | GTK maintenance。combo/clear/swap は Qt のみ layout あり |
| **GTK Main Swap L/R** | GTK layout に swap ボタンなし（既存 backlog） |
| **profile 選択時の R resolve 単体テスト** | impl は `_resolve_slideshow_srcdirs_for_start` で R スキップ済み。profile 経路は mock 重め → follow-up 可 |
| **Manage dialog 内 profile R slot 編集** | planning §2.2 — 単 display でも dialog は塞がない |
| **`_remote_slideshow_sync_targets` の R スキップ** | start 直前 resolve で R クリア済み。同期先列挙のみの軽微事項 |
| **解像度 `auto` と settings 持ち越し** | P-03 外。実機で確認済み（`auto` → primary 解像度） |
