## 検出ギャップと対応

### 本 feature で意図的に残す項目

| 項目 | 理由 |
|------|------|
| **GTK `on_source_catalog_saved`** | Manage dialog は Qt のみ。GTK registry parity は C-02 follow-up。実行中 catalog 変更 stop は Qt 経路で spec 充足。 |
| **GVFS path 専用読み取り** | オーナー決定（#2）。観測: [20260602-c02-real-device-observations.md](20260602-c02-real-device-observations.md)。Windows UNC / `/mnt` 推奨は planning / source-spec §4.1。 |
| **tick 毎 resolve** | 非採用（#3）。NAS 一時切断は既存 inaccessible → stop に委譲。 |
| **PyGObject / smbprotocol** | 非採用（Qt 寄せ・認証複雑化回避）。 |
| **段 4 追加 GUI** | 7-2 想起なし。status は既存 `last_error` / stop メッセージで足りる。 |
| **CLI registry** | 打ち止め（C-02 継続）。 |

### 実機メモ（audit 外・参照）

| 環境 | 結果 |
|------|------|
| Windows G: / UNC NAS | `local-dir` のまま動作（オーナー確認） |
| Linux GVFS（Thunar） | 登録可・slideshow 失敗しうる（観測のみ） |
| Linux `/mnt` 直指定 | 想定どおり（未検証） |
