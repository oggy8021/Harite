## v2.0.0 以降の変更棚卸

### Wave 1 — tray + tick 失敗 UI（#492, #494） — PR #499

- トレイ → Settings / Color / About で main window を raise しない。
- tick 失敗時に tray / main / footer 赤文字を同期。

### Wave 2 — slideshow tick 継続性（#493, #497） — PR #500

- JMA 更新なし tick は optimize+apply を skip（`no_remote_update`）。
- 一時的 display 失敗は pause（hard stop 回避）。
- intentional upscale 後 fit 不能時は down-only フォールバック。

### Wave 3 — settings keyword（#496） — PR #501

- Settings Save で `codh_keyword` / `ndl_keyword` を保持。

### Wave 4 — deferred apply（#495） — PR #502

- running 中の interval / slideshow auto scale 変更を次 tick へ延期（gui-spec §6.2.2）。

### Wave 3b — pending remote apply（#503） — PR #504

- display pause で apply だけ落ちた JMA cache 更新を、次 tick で回収。

### 耐障害性（#505） — PR #510

- 0 バイト `harite-sources.json` / `harite-settings.json` を空 catalog / `{}` として load。
